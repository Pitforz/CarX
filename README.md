# CarX

Хоррор от первого лица в ливневых тоннелях Лас-Вегаса (хакатон, тема «Братья Карамазовы»).

Эта инструкция для тех, кто ни разу не открывал Unity. Делайте шаги по порядку, на всё уйдёт 30–60 минут (большая часть — скачивание).

---

## 1. Что установить (один раз)

| Программа | Где взять | Зачем |
|---|---|---|
| **Git для Windows** | https://git-scm.com/download/win (все галочки по умолчанию, Git LFS ставится вместе с ним) | скачивать и отправлять проект; без него Unity не установит пакет Yarn Spinner |
| **Unity Hub** | https://unity.com/download | менеджер версий Unity и проектов |
| **Unity 6000.6.9f1** | см. ниже | сам редактор, **строго эта версия** |

**Как поставить нужную версию Unity.** Откройте Unity Hub и войдите в аккаунт Unity (бесплатная лицензия Personal). Потом вставьте в адресную строку браузера ссылку
`unityhub://6000.6.9f1/8c45277fb9c5` — Hub сам предложит установить именно эту версию.
Если ссылка не сработала: Unity Hub → **Installs** → **Install Editor** → вкладка **Archive** → найдите **6000.6.9f1**.
Модули при установке: достаточно **Microsoft Visual Studio Community** (если ещё нет редактора кода) и **Windows Build Support (IL2CPP)** (нужен для сборки игры в .exe). Остальное не нужно.

> Почему строго эта версия: другая версия «апгрейдит» проект, и после этого у остальных всё ломается. Если Hub предлагает открыть проект в другой версии — отказывайтесь.

## 2. Скачать проект

Откройте **Командную строку** (Win+R → `cmd` → Enter) и выполните по очереди:

```
git lfs install
cd /d C:\Dev
git clone https://github.com/Pitforz/CarX.git
```

Папку `C:\Dev` можно взять любую, но **без русских букв и пробелов в пути**.
Картинки, модели и звуки лежат в Git LFS и скачиваются вместе с проектом. Если потом в Unity текстуры розовые или пустые, выполните в папке проекта `git lfs pull`.

Вместо командной строки можно использовать **GitHub Desktop** (File → Clone repository → URL → `https://github.com/Pitforz/CarX.git`).

## 3. Открыть проект в Unity

1. Unity Hub → **Projects** → **Add** → **Add project from disk** → выберите папку `CarX` (ту, где лежат `Assets`, `Packages`, `ProjectSettings`).
2. Проект появится в списке, рядом будет версия **6000.6.9f1**. Нажмите на него.
3. Первое открытие идёт долго: **5–20 минут**. Unity скачивает пакеты и строит папку `Library`. Это нормально, ничего не трогайте.
4. Если появилось окно **Enter Safe Mode?** — значит, в коде ошибка компиляции. Нажмите **Ignore**, откройте **Window → General → Console** и пришлите красные строки программисту.
5. Если появилось окно **Administrator Privileges Detected** — нажмите **Restart as Standard User**. Unity не нужно запускать от имени администратора.

## 4. Пакеты и ассеты: ставить ничего не надо

Всё нужное ставится **само** при первом открытии (список лежит в `Packages/manifest.json`):

- **Universal Render Pipeline (URP)** — графика;
- **Input System** — управление;
- **Cinemachine** — камера игрока;
- **ProBuilder** — моделирование уровней прямо в Unity;
- **AI Navigation** — навигация NPC;
- **Splines**;
- **Yarn Spinner** — диалоги (качается с GitHub, поэтому нужен установленный Git);
- **Unity AI Assistant** — необязательный помощник внутри редактора, может просить вход в аккаунт, можно игнорировать.

Ассеты, которые уже лежат в репозитории и ничего не требуют:

- `Assets/Starter Assets` — контроллер игрока от первого лица (Unity Starter Assets);
- `Assets/_Project` — всё наше: сцены, скрипты, шейдеры, материалы, сгенерированные текстуры.

**Не входит в репозиторий:** персонажи и анимации **Mixamo** (`Assets/ThirdParty/Mixamo`, около 570 МБ). Бесплатный GitHub LFS даёт только 1 ГБ места и 1 ГБ скачиваний в месяц, поэтому эту папку передаём архивом отдельно (спросите у Фёдора). Без неё не работает только сцена `NPC_Demo`: NPC будут без моделей. Архив распакуйте так, чтобы получилось `Assets/ThirdParty/Mixamo/Characters` и `Assets/ThirdParty/Mixamo/Animations`.

## 5. Окна Unity за минуту

- **Hierarchy** (слева) — список объектов открытой сцены.
- **Scene** (центр) — редактор уровня. Крутить камеру: зажать **правую кнопку мыши** и двигать мышь, летать — **ПКМ + WASD**. Приблизиться к выбранному объекту — клавиша **F**.
- **Game** — то, что видит игрок.
- **Inspector** (справа) — настройки выбранного объекта.
- **Project** (снизу) — файлы проекта.
- **Console** (снизу, вкладка рядом с Project) — ошибки и сообщения.

Если какое-то окно пропало: **Window → Layouts → Default**.

## 6. Как запустить уровень

1. Внизу в **Project** откройте папку **Assets → _Project → Scenes**.
2. Дважды кликните по сцене (список ниже).
3. Нажмите **▶ Play** вверху по центру. Кликните мышкой в окно **Game**, чтобы оно поймало мышь и клавиатуру.
4. Выйти из игры — снова нажать **▶** (или **Ctrl+P**). Отпустить мышь во время игры — **Esc**.

> ⚠️ Всё, что вы меняете в сцене **во время Play**, после остановки пропадает. Кнопка Play подсвечена синим — значит, вы в игре.

**Управление:** WASD — ходьба, мышь — взгляд, Shift — бег, Space — прыжок, **F — фонарик** (в TunnelMaze_Demo).

| Сцена | Что это |
|---|---|
| **TunnelMaze_Demo** | Случайный лабиринт ливнёвок: 25 камер-развязок, тоннели разного сечения, лужи, песок, подъёмы наверх (ливнёвки с решёткой, люки с лестницей) с дневным светом. Фонарик на F. Главная демонстрация тоннелей. |
| **TunnelKit_Demo** | Ранний вариант: тоннель из готовых модулей-префабов (прямые, повороты, T, X). |
| **NPC_Demo** | Бездомные NPC с анимациями Mixamo (нужна папка Mixamo, см. п. 4). |
| **Sandbox** | Песочница Фёдора. Не редактируйте без спроса. |
| `Assets/Scenes/SampleScene` | Пустой шаблон Unity, не используется. |

**Целой игры пока нет**: сейчас это набор демо-сцен. Когда появятся уровни, их добавят в **File → Build Profiles → Scene List**, и игру можно будет собрать в .exe кнопкой **Build**.

## 7. Инструменты тоннелей (для тех, кто строит уровни)

Меню **CarX → Tunnels**:

- **New Tunnel Path** — новый тоннель. Он строится по точкам `Point_0, Point_1…` (дочерние объекты). Двигайте точки стрелками в окне Scene, тоннель перестраивается сам.
- **New Junction Chamber** — бетонная камера-развязка. Перетащите тоннели в поля North/East/South/West и нажмите **«Пристыковать тоннели»**: проём в стене вырежется по форме тоннеля.
- **Build Random Maze Demo** — заново собрать случайный лабиринт (перезаписывает сцену TunnelMaze_Demo).
- **Add Atmosphere** — темнота, туман и пост-эффекты для открытой сцены.
- **Regenerate Textures and Materials** — пересоздать процедурные текстуры бетона, грязи, песка и т. д.

В инспекторе тоннеля (выделите объект с компонентом **Tunnel Path**):
- сечение: восьмиугольник, короб с бордюрами, квадрат, прямоугольник, круглая труба;
- кнопки **+ Ливнёвка / + Решётка / + Люк** — подъём наверх; двигать его вдоль тоннеля жёлтым шариком в окне Scene;
- **Раскидать лужи и песок** / **Убрать лужи и песок**;
- все числа (длина плит, щели, полоса грязи и т. д.) меняются на лету.

Подсказка: в окне Scene есть кнопка освещения (лампочка в верхней панели). Если в редакторе всё чёрное — это нормально, тоннели тёмные; включите/выключите освещение сцены этой кнопкой.

## 8. Как работать вместе

1. **Перед началом работы** получите свежую версию: `git pull` (или Fetch/Pull в GitHub Desktop). Unity при этом лучше закрыть.
2. Сохраняйте сцену: **Ctrl+S**.
3. Отправить изменения (Unity сохранить, можно не закрывать):
   ```
   cd /d C:\Dev\CarX
   git add -A
   git commit -m "Коротко, что сделано"
   git push
   ```
4. Правила:
   - **одну сцену одновременно правит один человек**, остальное — через префабы (сцены плохо сливаются);
   - файлы `.meta` всегда коммитятся вместе с файлом — не удаляйте их;
   - не коммитим `Library/`, `Temp/`, `Logs/`, `UserSettings/` (уже в `.gitignore`);
   - сторонние ассеты кладём в `Assets/ThirdParty/`, свои — в `Assets/_Project/`;
   - большие файлы (больше ~50 МБ) сначала обсудите: место в LFS ограничено.

## 9. Частые проблемы

| Симптом | Что делать |
|---|---|
| Hub пишет, что версия не установлена | Поставить 6000.6.9f1 (п. 1), не открывать в другой версии. |
| Всё розовое | Не скачались текстуры LFS → `git lfs pull` в папке проекта. Или открыто не той версией Unity. |
| Красные ошибки в Console после `git pull` | Подождать, пока Unity перекомпилирует (крутится значок справа внизу). Если не прошло — прислать текст ошибки программисту. |
| Ошибка про Yarn Spinner / git при открытии | Не установлен Git или Unity запущен до установки Git → поставить Git, перезапустить Unity Hub. |
| Персонаж не двигается | Кликнуть в окно Game. Проверить, что нажат Play. |
| Unity упал | Просто открыть заново; несохранённые изменения могут пропасть, поэтому чаще жмите Ctrl+S. |

## 10. Для программистов

- Наш код: `Assets/_Project/Scripts` (`Level` — генерация тоннелей, `Gameplay` — фонарик и пр., `Editor` — инструменты редактора), шейдеры — `Assets/_Project/Shaders`.
- `Assets/_Project/Scripts/Editor/CarXRemoteBridge.cs` — служебный мост, через который Claude управляет редактором (читает команды из `Logs/carx_cmd.txt`). Никому не мешает, в игру не попадает.
- Unity 6.6: `Object.GetInstanceID()` устарел и даёт ошибку компиляции — используйте `GetEntityId()` или `GetHashCode()`.
